## Развёрнутая версия (канал / сайт)

### Зачем

Раньше Premium давал push по категориям и фильтр **только по метро**. Этого мало: кто-то работает в Подмосковье, кому-то важна **ставка**, кто-то не хочет будить телефон **ночью**, но хочет смотреть вакансии **утром в ленте**.

### 🎯 Фильтры Premium — одно место настроек

Путь: **⚙️ Настройки → 🎯 Фильтры Premium** (доступно на Premium и Trial).

#### 📍 География
- Города Московской области из справочника  
- «Москва — любая» или только выбранные **станции метро**  
- **Радиус от города** — если в объявлении есть координаты, подойдут точки рядом с выбранным городом  
- Можно показывать вакансии **без адреса** (по умолчанию — да)

#### 💰 Ставка
- Для каждой категории — порог **₽/ч** и/или **₽/смена**  
- Если ставку не удалось распознать — вакансия **не скрывается**

#### 📅 Смена
- **Без ночных** (старт 22:00–06:00)  
- **Только сегодня и завтра**  
- **Не раньше** заданного времени (08:00, 09:00, …)

#### 🔔 Push и уведомления
- **Тихие часы** — своё время «не беспокоить» (МСК)  
- **🔕 Занят 2 ч** / **🌙 До утра** — push пауза, лента доступна  
- **Сводка после паузы** — «пока уведомления были выключены, опубликовано N подходящих вакансий»  
- По категориям: обычный push / **только лента**

#### 📋 Лента
- По умолчанию фильтры режут **только push**  
- Можно включить **«Фильтры и в ленте»** — те же правила, что для push (кроме тихих часов)

### 🗺 Карты и парсер
- Адреса и ставки извлекаются из текста точнее  
- Кнопка **«На карте»** использует координаты, если они есть в посте  

### Подписка
- **Free:** 1 категория, лента, без push и без фильтров  
- **Premium:** все категории, push, полный набор фильтров  
- Настройки фильтров **не сбрасываются** при окончании Premium
